# Sample Small Easy

Small, mostly easy — 70% deterministic. Quick demo (~30s with AI).

- **Records**: 30
- **Seed**: 101
- **Distribution**: perfect_match=55%, fee_adjusted=15%, date_drift=10%, partial_refund=5%, duplicate_order=5%, orphan_settlement=4%, orphan_order=3%, split_settlement=3%

## Files
- `settlement_report.csv` — Settlement records from gateway
- `order_ledger.csv` — Merchant order records

## Usage
Upload both CSV files in the dashboard's **Upload & Reconcile** tab.
